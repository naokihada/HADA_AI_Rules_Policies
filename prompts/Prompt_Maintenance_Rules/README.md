# 日本語

# Prompt_Maintenance_Rules

HADA 形式のプロンプトを保守するための標準ルールパッケージ。

## 目的

HADA 形式のプロンプトを保守するためのルール。プロンプトの意味を保持し、生成性能を維持し、保守性を向上させ、冗長性を削減し、トークン使用量を最小限に抑えることを目的とする。
