Rules for operating and maintaining AI coding agents in an agent-independent way: reduce agent dependency, ensure interoperability across agents, preserve project knowledge and reusable work history, enable safe automation, and improve maintainability and auditability.

# 日本語

# Coding_Agent_Operations_Maintenance_Policy

AI コーディングエージェントの運用・保守ポリシーの HADA 標準プロンプトパッケージ。

## 目的

AI コーディングエージェントをエージェント非依存の方式で運用・保守するためのルール。エージェント依存の削減、複数エージェント間の相互運用性の確保、プロジェクト知識および再利用可能な作業履歴の保持、安全な自動化の実現、保守性および監査性の向上を目的とする。
